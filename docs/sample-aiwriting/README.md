## 9장 역할

| # | 역할 | 핵심 메시지 |
|:---|:---|:---|
| 1 | Cover | AI 글이 어색한 건 모델 탓이 아니라 지시문 탓이다. 같은 AI로 달라지는 7가지 비교 |
| 2 | BEFORE/AFTER 01 - 독자와 목적 명시 | '블로그 글 써줘' 대신 누가 읽고 읽은 뒤 무엇을 하길 바라는지 한 줄로 먼저 적는다 |
| 3 | BEFORE/AFTER 02 - 톤은 샘플로 | '친근하게 써줘' 대신 내가 쓴 글 한 단락을 보여 주고 이 말투로 쓰라고 시킨다 |
| 4 | BEFORE/AFTER 03 - 개요 먼저 | 완성본을 한 번에 요구하지 말고 개요를 먼저 받아 확정한 뒤 본문을 쓰게 한다 (수치 없이 흐름도로 표현) |
| 5 | BEFORE/AFTER 04 - 하지 말 것 지시 (반전) | '잘 써줘'를 더하는 것보다 '감탄으로 시작하지 마' 같은 금지 한 줄을 넣는 쪽이 AI 티를 더 빨리 지운다 |
| 6 | BEFORE/AFTER 05 - 고칠 기준 지정 | '더 좋게 고쳐줘' 대신 반복되는 단어, 긴 문장처럼 고칠 기준을 콕 집어 준다 |
| 7 | BEFORE/AFTER 06 - 사실 확인 목록 | 받은 글을 그대로 붙여 넣지 말고 숫자·날짜·고유명사만 목록으로 뽑게 해서 직접 확인한다 |
| 8 | BEFORE/AFTER 07 - 첫 문장은 내가 (클라이맥스) | 끝까지 AI에게 맡기지 말고 첫 문장과 마무리 한 줄은 내 경험으로 직접 쓴다. 그 한 줄이 사람 글을 만든다 |
| 9 | Outro | 다음 글 쓰기 전에 꺼내 볼 수 있게 저장해 두고, After 지시문을 그대로 복사해 쓰세요 |
